Chi tiết phiếu công tác

Truy vấn trực tiếp từ appct.evnhcmc.vn (Qua API Proxy)

Do máy chủ appctapi.evnhcmc.vn chặn CORS từ github.io, để đăng nhập và lọc ngày trực tiếp trên trình duyệt bạn cần điền URL Cloudflare Worker (xem file cloudflare-worker/worker.js). Nếu dùng chế độ tự động của GitHub Actions, bạn không cần dùng mục này.
