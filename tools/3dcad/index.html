CAD 2D/3D Hướng dẫn sử dụng & Hỗ trợ định dạng AutoCAD

1. Đọc & Xuất File AutoCAD (.DXF / .DWG):

  • Đọc trực tiếp .DXF: Hỗ trợ đầy đủ các đối tượng AutoCAD gồm LINE, LWPOLYLINE, POLYLINE, CIRCLE, ARC, ELLIPSE, TEXT, MTEXT, 3DFACE, SOLID, POINT, tự động nhận diện Layer, màu chuẩn AutoCAD Color Index (ACI 1–255) và độ dày 3D (Thickness / Z-Elevation).
  • Về định dạng .DWG: Nếu bạn chọn một file .dwg nhị phân đóng, trình duyệt sẽ kiểm tra cấu trúc hoặc hướng dẫn bạn lưu sang AutoCAD .DXF (Lệnh SAVEAS hoặc DXFOUT trong AutoCAD) để đọc 100% vector chính xác.
  • Xuất File .DXF: Nhấn nút Xuất .DXF để tải về file chuẩn AutoCAD mở được ngay trên AutoCAD, BricsCAD, ZWCAD, FreeCAD, Rhino.

2. Phím tắt & Lệnh Command Line:

L : Vẽ đoạn thẳng (Line)
PL : Đường đa tuyến (Polyline)
REC : Hình chữ nhật (Rect)
C : Hình tròn (Circle)
A : Cung tròn (Arc)
DIM : Đo kích thước
BOX / CYL : Khối 3D
ESC / Enter : Kết thúc lệnh
